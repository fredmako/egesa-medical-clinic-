# Egesa Medical Clinic

Modern healthcare website built with React 19, TypeScript, Tailwind CSS v4, and Vite.

## Pages

- Home
- About
- Services
- Laboratory
- Special Clinics
- Patient Rights
- Family Planning Education
- Contact
- Appointment Booking

## Scripts

- `npm run dev` — start dev server
- `npm run build` — production build
- `npm run preview` — preview build locally

## Tech

- React 19
- TypeScript
- Tailwind CSS v4
- React Router
- Lucide React
